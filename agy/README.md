# Optimisal (Antigravity Plugin)

Connect Google Antigravity to Optimisal at `https://dashboard.optimisal.app/mcp` using OAuth to triage Roblox incidents, inspect errors, review economy health, run A/B & storefront experiments, and manage LiveOps safely.

## Install

Copy or install this folder into `~/.gemini/config/plugins/optimisal` (or `.agents/plugins/optimisal` in your workspace), then enable **Optimisal** on the Customizations page.
