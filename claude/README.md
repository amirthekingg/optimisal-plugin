# Optimisal for Roblox (Claude Code Plugin)

Connect Claude Code to Optimisal at `https://dashboard.optimisal.app/mcp` using browser OAuth to triage Roblox incidents, inspect errors, review economy health, run A/B & storefront experiments, and manage LiveOps safely.

## Install

```text
/plugin marketplace add amirthekingg/optimisal-plugin
/plugin install optimisal@optimisal
```
